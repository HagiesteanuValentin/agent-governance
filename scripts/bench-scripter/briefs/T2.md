# Brief 0 — măsurători pagina de produs (scripter, Opus 5.5 low)
Scop: script de verificare refolosibil + măsurătorile „înainte” pentru /produs/[slug] și tranziția catalog → produs.
Rădăcină: directorul curent al repo-ului (lucrezi DOAR aici).
Pași:
1. Citește docs/polish/produs.dosar.md (selectori, breakpoints, rețeta de capturi) și regula „Task cu mai multe briefuri” din CLAUDE.md.
2. Scrie scripts/verifica-produs.mjs (Playwright). Portul e argument (`--port <PORT din CELL.env>` implicit), ca același script să ruleze în alte worktree-uri pe alte porturi. Măsoară pe 360/390/768/1280/1440, pentru cele 3 produse (cifra-aniversara, lampa-fagure, vaza-ondulata): poziții și dimensiuni h1/galerie/conținut, overflow orizontal, contraste text, CLS, dacă există tranziție la click din `/` pe un card (durată, vizibil sau nu), JS trimis pe pagină (KB gzip). Capturi reduse `-mic.png` la 390, 768, 1440 în docs/polish/capturi-produs/.
3. Pornești `npm run dev -- --port <PORT din CELL.env> --strictPort` dacă nu rulează, rulezi scriptul, scrii docs/polish/produs.masuratori.md (≤3.000 caractere): cifre pe lățimi + căile celor 3 capturi. Nu propui itemi.
Gata când: scriptul rulează cu exit 0 de 2× cu aceleași cifre; masuratori.md există, ≤3.000 caractere.
Script de măsurători, nu transformare: fără dry-run/SCRIPTS.md, idempotență = aceleași cifre de 2×.
Interzis: commit, push, seed, servicii reale; editări în src/; alte fișiere decât scriptul, masuratori.md, capturile. Oprești serverul dev pornit de tine la final.
