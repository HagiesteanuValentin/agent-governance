# Brief 0 — scriptul de măsurători pentru mișcarea paginii / · Lucrător: scripter (Opus 5.5 low)
Scop: script refolosibil care măsoară mișcarea paginii `/` + capturi + fișierul de cifre „înainte". Surse: `docs/polish/index.dosar.md` (căi, selectori, URL, breakpoints, scripturi existente). Nu citi DECIZII sau RETETE integral; doar secțiunile numite în dosar.
1. Scrii `scripts/verifica-index-miscare.mjs` (Node + Playwright); refolosește helperii din scripts/verify-index.mjs / verifica-scena.mjs fără să le modifici. Dev server http://localhost:<PORT din CELL.env>/ (pornești `npm run dev -- --port <PORT> --strictPort` dacă nu răspunde; scriptul acceptă `--url`, implicit acest URL).
2. La 390×844, 900×900, 1440×900: derulezi în pași de 2% din înălțimea paginii; pentru fiecare element animat din dosar (straturi scenă, h1/subtitlu hero, vaza/inele, filament, texte secțiuni, poze, Contact/footer) notezi opacity, transform calculat, clip-path, vizibil da/nu.
   Pe element scoți: % scroll la start, % la starea finală, câte % ține starea finală înainte de ieșire, ajunge vreodată la final da/nu (opacity 1 / transform none).
   Plus: intervale cu două straturi ambele opacity >0,1; intervale cu ecran gol; overflow orizontal; CLS (PerformanceObserver).
   Rulare în plus cu `prefers-reduced-motion: reduce` și cu fallback-ul fără view() (ca `--fara-view` din verifica-scena.mjs): totul vizibil da/nu, overflow.
   3 capturi `-mic.png` (≤800px lățime) la cele 3 lățimi, în repaus pe hero, în `docs/polish/capturi-miscare/`. JSON în `docs/polish/capturi-miscare/masuratori.json`; exit 0 dacă a rulat.
3. Rulezi de 2×; cifrele trebuie să fie identice.
4. Scrii `docs/polish/index.masuratori.md` (≤3.000 caractere): pe lățimi, tabel pe element (start / final / ține / ajunge la final), suprapuneri, ecran gol, overflow, CLS, reduced-motion, fallback, căile capturilor. Fără propuneri, fără itemi.
Script de măsurători, nu transformare: fără dry-run/SCRIPTS.md, idempotență = aceleași cifre de 2×.
Fișiere permise: scriptul, masuratori.md, `docs/polish/capturi-miscare/*`. Gata când: exit 0 de 2× cu aceleași cifre, masuratori.md ≤3.000, 3 capturi.
Interzis: commit, push, seed, servicii reale; orice modificare în src/; `npm run build`; oprirea altui dev server decât cel pornit de tine (pe al tău îl oprești la final).
